A FEW GOOD QUESTIONS

你可能还想知道。

关于体验、数据和部署的小事。

这里的 Demo 是真实验证吗？+

是。Demo 使用当前服务的真实 PoW、图片挑战和一次性令牌。验证通过后，还可以点击“提交到服务端核验”，体验令牌的服务端消费过程。当前服务的验证模式和难度由部署配置决定。

会收集我的哪些数据？+

组件采集有限的交互轨迹和表单时间统计，不读取表单输入内容，也不采集画布指纹。服务端使用 IP 绑定挑战和令牌，验证状态按有效期清理；部署者负责自己的访问日志策略。

可以部署在自己的服务器吗？+

可以。支持 Node.js ≥ 22.5 和 Cloudflare Workers。Node.js 默认使用内存存储，Workers 使用 SQLite Durable Objects；无需依赖外部验证码服务。

支持手机和键盘操作吗？+

支持。可以用鼠标或触屏拖动滑块，也可以用方向键微调并按 Enter 确认。按 Escape 可取消。组件适配深浅主题，并尊重减少动态效果的系统偏好。
